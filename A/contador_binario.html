El corazón del flujo de programa

Este circuito es el Program Counter (PC) de tu microprocesador. Su función es indicar qué dirección de memoria contiene la siguiente instrucción.

  • Incremento: Con cada pulso de reloj (botón azul), el contador avanza. Así el procesador lee la instrucción 0, luego la 1, la 2, etc.
  • Carga (JUMP/BRANCH): El botón morado "Cargar" simula una instrucción de salto (como GOTO, JMP o IF). Permite cambiar bruscamente el valor del contador para repetir código o saltar a otra función.
