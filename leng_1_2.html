Operaciones: Concatenación y Kleene

← Volver

1. Concatenación

La concatenación es la operación fundamental de "pegar" secuencias. Puede aplicarse tanto a cadenas individuales como a lenguajes completos.

Concatenación de Cadenas

Dadas dos cadenas u y v, su concatenación uv consiste en formar una nueva cadena con los símbolos de u seguidos de los de v.

Ejemplo: Si u = "casa" y v = "blanca"
uv = "casablanca"
vu = "blancacasa" (No es conmutativa)

Propiedad de Identidad: La cadena vacía (ε) es el elemento neutro.

w ε = ε w = w

Concatenación de Lenguajes

Dados dos lenguajes L1 y L2, su concatenación L1 ⋅ L2 es el conjunto formado por todas las combinaciones posibles tomando una cadena del primero y una del segundo.

Definición Formal: L1 ⋅ L2 = { xy | x ∈ L1, y ∈ L2 }
Ejemplo de Conjuntos: L1 = {0, 1}
L2 = {a, b}
L1 ⋅ L2 = {0a, 0b, 1a, 1b}

2. Potencia de un Lenguaje

Para entender la Clausura de Kleene, primero debemos definir la potencia de un lenguaje. Consiste en concatenar un lenguaje consigo mismo n veces.

  • L0: Por definición, es siempre { ε } (conjunto que contiene solo la cadena vacía).
  • L1: Es el mismo lenguaje L.
  • L2: Es L ⋅ L.
  • Ln: Es L ⋅ Ln-1.
Ejemplo visual: Sea L = {a}
L0 = {ε}
L1 = {a}
L2 = {aa}
L3 = {aaa}

3. Clausura de Kleene (Estrella)

La Clausura de Kleene, denotada como L* (o Sigma estrella Σ* si hablamos del alfabeto), representa la unión infinita de todas las potencias posibles de un lenguaje.

Fórmula Maestra: L* = L0 ∪ L1 ∪ L2 ∪ L3 ... ∪ L∞

En términos simples: es el conjunto de todas las cadenas posibles (de cualquier longitud, incluyendo cero) que se pueden formar con los símbolos disponibles.

Diferencia con Clausura Positiva (L+)

Concepto Notación Definición ¿Incluye ε?
Clausura de Kleene L* Cero o más repeticiones SÍ (siempre)
Clausura Positiva L+ Una o más repeticiones NO (a menos que L ya tenga ε)
Ejemplo Comparativo: Sea Σ = {a}

Σ* = {ε, a, aa, aaa, aaaa, ...}
Σ+ = {a, aa, aaa, aaaa, ...}

Relación: L+ = L ⋅ L*.
