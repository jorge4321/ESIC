1. Estructura de una Regla

No-Terminales (Mayúsculas) Terminales (Minúsculas)

Una regla de producción es el mecanismo fundamental de reescritura en una gramática. Define cómo un símbolo puede ser reemplazado por otros.

A → BaC

Se lee: "El símbolo A produce (o puede ser reemplazado por) la cadena BaC".

  • Parte Izquierda (Cabeza): Lo que vamos a reemplazar.
  • Parte Derecha (Cuerpo): Por lo que lo reemplazamos.

2. Ejemplo de Derivación

Una derivación es la secuencia de sustituciones, partiendo del Símbolo Inicial, hasta obtener una cadena formada únicamente por símbolos terminales.

Gramática de Ejemplo (Balanceo de paréntesis):

1. S → ( S ) 2. S → S S 3. S → ()

Objetivo: Generar la cadena "( ( ) )"

S Inicio
( S ) Aplico Regla 1
( ( S ) ) Aplico Regla 1 (al S interno)
( ( ) ) )
Nota sobre el paso final:
En el último paso, el S restante se sustituye por () (o epsilon si la gramática lo permitiera) para cerrar la cadena.
